# Installer Zach'Lab

Zach'Lab fonctionne sur **Windows**. Il faut environ deux minutes.

## 1. Télécharger

Choisis le logiciel (ou les deux) :

- **Zachar't Mentale** (cartes mentales) : [Télécharger](https://github.com/aifedespaix/Zach-Lab/releases/download/updater-zachart/Zachart-Mentale-setup.exe)
- **Zach'Math** (fiches et exercices de maths) : [Télécharger](https://github.com/aifedespaix/Zach-Lab/releases/download/updater-zachart-maths/Zachart-Maths-setup.exe)

## 2. Installer

1. Ouvre le fichier téléchargé (`Zachart-…-setup.exe`).
2. Si Windows affiche « Windows a protégé votre PC », clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Suis les étapes de l'installeur.

## 3. Ouvrir

Lance le logiciel depuis le menu Démarrer ou depuis son raccourci sur le bureau.

Les mises à jour se font ensuite toutes seules depuis l'application. Rien à réinstaller.
